# Paderborn source measurements

The original University of Paderborn Bearing DataCenter MAT recordings are **not included** in this repository. Obtain them from the [official Bearing DataCenter](https://mb.uni-paderborn.de/en/kat/research/bearing-datacenter/data-sets-and-download) and respect its terms.

The canonical experiment uses 15 separate bearings and two operating conditions: N09_M07_F10 and N15_M07_F10. The supplementary load experiment uses N15_M01_F10 and N15_M07_F04. File and archive inventories are included in the private staging ZIP.

Do not add raw measurements to this repository. Place them in an ignored raw/ directory or another local folder.
