# Code provenance

The original transient Stage G/H execution code from the earlier manuscript-development run was not preserved as a standalone source file. This package is a later reconstructed and frozen canonical implementation.

The reconstruction is grounded in: (1) the preserved public-data manifest and archive checksums; (2) byte-identical legacy preprocessing code retained from the earlier controlled Paderborn stage; (3) the method equations and parameter grids documented in the manuscript; and (4) newly rerun task-level outputs, predictions, ablations, UDA/noise experiments, and logs.

The updated submission manuscript uses the results generated by this canonical package. Historical manuscript numbers are not silently inserted into the new result files. Where a historical and rerun value differ, the updated manuscript reports the rerun value.
